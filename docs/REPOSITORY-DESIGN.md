# 仓库展示设计

本轮仅调整GitHub仓库首页、展示素材、文档入口和仓库简介。保留产品的深绿、暖白与浅绿视觉，不改应用UI、业务代码或现有许可证状态。

## 参考了什么

2026-10-24实际阅读下列项目的GitHub首页与README。参考信息结构，不复制其文案、品牌资产、截图或社区数据。

| 参考项目 | 借鉴方式 | Flow Console中的应用 |
| --- | --- | --- |
| [Dify](https://github.com/langgenius/dify) | 品牌入口、清晰定位、导航与能力概览 | 首屏封面、简短产品介绍、快速入口 |
| [Vue Vben Admin](https://github.com/vbenjs/vue-vben-admin) | 先看到产品，再进入文档与安装 | 实际Vue页面截图、可展开的其他界面、文档中心 |
| [Coolify](https://github.com/coollabsio/coolify) | 快速说明用途，并提供直接的启动入口 | 工作流概览、三步启动、清晰的服务访问说明 |

不增加虚构的在线演示地址、用户数量、性能倍数或开源许可证徽章。

## 首页阅读顺序

1. **封面和定位**：这是什么、用于什么业务。
2. **功能与页面**：把商品资料、审核与执行放到同一个工作区。
3. **可靠性与架构**：版本审核、任务持久化、未知结果核验的实现依据。
4. **快速开始**：如何启动、访问和停止。
5. **文档与边界**：按读者目的导航，明确真实平台与测试证据的区别。

## 资产维护

- `images/repository-cover.svg`：可编辑的矢量封面；PNG为其实际浏览器渲染，用于一致显示中文字体。
- `images/showcase-*.png`：当前Vue页面配合显式合成数据的截图，用于界面展示，不用于证明平台发布成功。
- `../scripts/capture-repository.cjs`：可复现截图与封面渲染。它只拦截浏览器中的演示API，不启动数据库，不访问真实店铺。
- 原`workbench-java*.png`及历史验收截图保留，继续关联原始证据。

README使用GitHub支持的Markdown、表格和`details`折叠，核心封面与截图放在仓库内。技术徽章只是辅助信息；CI徽章链接到真实Actions工作流。
