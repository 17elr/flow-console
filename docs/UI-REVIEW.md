# 前端UI复查 · 2026-10-24

使用实际Vue页面与隔离Java测试API，在Edge无头浏览器检查1440、768和375px宽度。覆盖登录、商品六个标签页、导入、任务、店铺、成员与审计，共32个页面状态截图；无JavaScript异常、Vue警告、异常HTTP响应、破图或页面级横向溢出。数据为合成测试数据，真实平台和收费模型关闭。

本轮修复：

1. 商品B读取失败后切换商品，会把A的表单缓存成B的草稿。现在草稿只保存到该表单实际加载的商品ID，保留A的未提交修改。
2. 图片与合规文件上传失败后，自动刷新会清除错误提示。现在失败时保留提示并允许重新选择同一文件；只有成功才刷新素材。
3. 切换Excel、成品图或ZIP导入方式后，界面残留旧文件名而实际文件控件已清空。现在同步清理文件、目录和结果状态，提交期间禁用切换。
4. 从已滚动页面切换导航后，新页面停在旧滚动位置。现在导航完成后回到顶部。
5. 从店铺等页面退出后重新登录，仍停在旧管理页面。现在登录成功进入商品工作台。小屏图标导航同时补上可访问名称。

前四个问题先通过浏览器用例复现失败；修复后的5个回归用例均通过，见`web/e2e/ui-review.spec.js`。原有测试继续检查加载锁定、会话过期草稿保留、审核、导入、任务和响应式布局。Vue构建与fetch单测通过。

本轮未改动业务数据库、平台发布逻辑或视觉风格。没有对所有浏览器和真实店铺状态作无差异保证。
