# Flow Console 工作台设计

本次沿用旧版已有的深绿品牌色、浅灰绿色画布、白色面板、细边框和商品业务顺序。参考为 `docs/images/workbench.png` 和 `apps/web/src/app/globals.css`。不是新的营销首页。

已执行全局 `ui-ux-pro-max/scripts/search.py` 的设计系统搜索与 Vue 表单/异步/可访问性搜索。设计系统搜索返回电商营销展示页的强色块建议，与现有内部工作台不匹配，因此保留项目已有色板及系统中文字体；采用搜索中适用的语义控件、可见焦点、内联错误、生命周期清理、窄屏和减少动效规则。未新增字体下载与装饰图片。

页面分为商品工作台、批量导入、任务与结果、店铺配置、成员与审计。工作台保留商品列表与资料/素材/文案/审核/店铺的主要操作关系；详细区域用标签页减少长页面重复内容。六张主图维持原定顺序，SKU图独立显示。

- 绿色：`#166749`，主导航：`#173d30`，画布：`#f4f7f5`，文本：`#182d24`。
- 状态同时显示文字与颜色；未配置、权限不足、缺资料、审核拒绝、部分导入失败都提供具体说明。
- 金额使用文本输入及服务端十进制校验，接口将BigDecimal输出为字符串，避免JavaScript悄悄改变价格精度。
- 提交失败保留表单；切换商品取消旧请求并忽略旧响应；页面离开或隐藏时停止任务轮询。
- 375、768、1440px浏览器检查，无页面级横向溢出；小屏保留图标导航及可访问名称，商品列表转横向卡片区域。

新版截图来自独立数据库中的合成验收商品。截图中的任务计数也是HTTP假平台产生的测试数据，不代表真实店铺结果或生产效率。
